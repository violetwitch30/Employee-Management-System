# Employee Management System

Employee Management System built with Angular frontend and Node.js + GraphQL backend.

---

## Project Structure

- `frontend` — Angular application  
- `backend` — Node.js, Express, GraphQL API  

---

## Features

- User signup and login with JWT authentication  
- View all employees  
- Add employee  
- Edit employee  
- Delete employee  
- Search employees by department or designation  
- View employee details  
- Upload employee photo using Cloudinary  

---

## Technologies Used

### Frontend
- Angular  
- Bootstrap  
- TypeScript  

### Backend
- Node.js  
- Express  
- GraphQL  
- MongoDB Atlas  
- Cloudinary  
- JWT Authentication  

---

## Running Locally

### Backend

```bash
cd backend
npm install
npm start
```

Runs on ```http://localhost:5000/graphql```

### Frontend
```bash
cd frontend
npm install
ng serve
```

Open ```http://localhost:4200```
